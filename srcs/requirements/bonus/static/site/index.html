Proyecto Inception

Infraestructura desplegada con Docker Compose dentro de una máquina virtual. Tres servicios obligatorios, cada uno en su propio contenedor construido desde Debian 12.

  • NGINX — único punto de entrada, TLS 1.2 y 1.3
  • WordPress — PHP-FPM, sin servidor web dentro
  • MariaDB — base de datos con volumen persistente

Esta página

Sitio estático servido por su propio contenedor NGINX, escrito en HTML y CSS. Forma parte de la parte bonus del proyecto.
